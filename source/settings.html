Fetching

Refresh every Minutes between fetches. Applies after a Restart.
Show completed tasks Off keeps the widget to what is still open.

What the widget shows

Group by list A card per task list, or everything in one card.
Show notes Task notes under the title, clamped to two lines.

Columns

Lists are dealt across the columns in turn, so column one takes the first list, column two the second, and round again. The window widens to fit.

Number of columns
Maximum tasks shown Caps the window height. 0 draws everything, which on a long list runs off the bottom of the screen: a window pinned to the desktop cannot grow past the screen height, and there is nothing to scroll. Anything left out is counted at the bottom.

Order

Drag to reorder, or use the arrows. This is the order lists are dealt into the columns.
